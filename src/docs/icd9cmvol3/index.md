# ICD-9-CM Volume 3 - Alphabetic Index to Procedures

This is the **Alphabetic Index to Procedures** for ICD-9-CM Volume 3 (2010 Edition with Indonesian Modification).

## How to Use This Index

The alphabetic index helps you locate procedure codes by searching alphabetically by the main term of the procedure. Each entry provides:

- The procedure name
- Related sub-procedures (indented under main terms)
- The corresponding procedure code
